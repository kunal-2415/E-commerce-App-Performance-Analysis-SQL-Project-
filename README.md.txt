# E-commerce App Performance Analysis using SQL.

---

## Project Overview
This project analyzes the performance of an e-commerce application using SQL. The goal is to extract business insights related to user behavior, sales performance, and operational efficiency.

---

## Objectives
- Measure app performance using key KPIs
- Analyze user engagement and conversion
- Identify operational issues
- Understand product demand trends


## KPIs Used
- Total Orders
- Total Revenue
- Total Users
- Active Users
- Logins
- Order Status Distribution
- Conversion rate


## Tools & Technologies
- PostgreSQL (PG Admin)
- SQL
- Excel (for validation)

---

## Key Insights

### 1. Revenue Growth
Revenue increased significantly in 2022, indicating improved monetization.

### 2. User Behavior
Active users decreased, but login activity remained stable, showing stronger engagement among fewer users.

### 3. Conversion Gap
Many users log in but do not place orders, indicating a conversion issue.

### 4. Operational Issue
High order rejection rate suggests problems in inventory or fulfillment.

### 5. Product Trends
Top-selling products changed over time, indicating shifting customer preferences.

---

## Project Structure
- SQL Queries for analysis
- Datasets used
- Business insights documentation
- Queries Screenshots

---

## Conclusion
The application shows strong revenue growth but faces challenges in user retention and order fulfillment. Improving conversion strategies and operational efficiency can further enhance performance.
